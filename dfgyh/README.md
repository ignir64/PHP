# Atelier POO

Exercices de l'atelier POO de la SAE 3.01

## Description

Ce dépôt contient divers exercices ayant pour but d'acquérir les bases de la Programmation Orientée Objet (POO) en PHP. 
Ces exercices seront abordés durant un atelier dédié lors de la SAE 3.01. 

## Structure du dépôt

- **classes** : Contient les différentes classes utilisées dans les exercices.
- **diagramme_de_classes** : Contient le diagrammes des classes UML utilisés pour les différents exercices.
- **images** : Ressources images utilisées dans les exercices.
- **index.php** : Point d'entrée principal pour les exercices PHP, notamment pour tester les classes élaborées.
- **recette_omelette_piments.txt** : Le descriptif d'une recette qui pourra être utilisé pour les exercices de l'atelier.


## Installation

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/patrick-etcheverry/atelier-poo.git
   ```
2. Accédez au répertoire du projet :
   ```bash
   cd atelier-poo
   ```

Durant l'atelier, au fur et à mesure des exercices, l'enseignant mettra à votre disposition les corrections. 
Ces corrections se trouveront dans des branches spécifiques que vous pourrez rapatrier sur votre machine lorsqu'elles seront disponibles.

### Comment récupérer les corrections

Lorsque la correction de l'exercice 1 sera disponible, vous pourrez la récupérer via la commande : 
```bash
git pull origin correction_exercice_1
```
Il vous suffira ensuite de basculer sur la branche récupérée pour consulter la correction :
```bash
git switch correction_exercice_1
```
